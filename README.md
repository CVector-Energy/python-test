# Python UV Test Action

Test UV-based Python projects using ruff, mypy, and pytest.

> **Note**: This is the UV-based version on the `uv` branch. For the Poetry-based version, see the `main` branch.

## What This Action Does

1. Install Python
2. Installs UV
3. Syncs dependencies (with caching)
4. Runs `ruff check` on source directories
5. Runs `ruff format --check` on source directories
6. Runs `mypy` on source directories
7. Runs `pytest`

## Inputs

| Input | Description | Required | Default |
|-------|-------------|----------|---------|
| `python-version` | Python version to use | No | `3.14` |
| `uv-version` | UV version to install | No | `0.10.2` |
| `src-dirs` | Source directories for linting (space-separated) | No | `.` |
| `working-directory` | Directory containing pyproject.toml | No | `.` |
| `run-pytest` | Whether to run pytest | No | `true` |

## Usage

### Basic Usage

```yaml
steps:
  - name: Checkout
    uses: actions/checkout@v6

  - name: Test with UV
    uses: CVector-Energy/python-test@uv
```

### With Custom Python Version

```yaml
steps:
  - name: Checkout
    uses: actions/checkout@v6

  - name: Test with UV
    uses: CVector-Energy/python-test@uv
    with:
      python-version: "3.12"
```

### With Custom UV Version

```yaml
steps:
  - name: Checkout
    uses: actions/checkout@v6

  - name: Test with UV
    uses: CVector-Energy/python-test@uv
    with:
      uv-version: "0.10.2"
```

### Matrix Testing

```yaml
jobs:
  test:
    runs-on: ubuntu-24.04
    strategy:
      matrix:
        python-version: ["3.11", "3.12", "3.13", "3.14"]

    steps:
      - name: Checkout
        uses: actions/checkout@v6

      - name: Test with UV
        uses: CVector-Energy/python-test@uv
        with:
          python-version: ${{ matrix.python-version }}
```

## Migrating from Poetry to UV

If you're migrating from the Poetry-based version (`@main`), you need to:

### 1. Update Your Project

**Convert pyproject.toml:**
- Move dev dependencies from `[tool.poetry.group.dev.dependencies]` to `[dependency-groups]`
- Remove `[tool.poetry]` section (keep `[tool.poetry.scripts]` if needed, but rename to `[project.scripts]`)
- Keep `[project]` section as-is

**Generate uv.lock:**
```bash
# Install UV
curl -LsSf https://astral.sh/uv/install.sh | sh

# Generate lock file
uv lock
```

### 2. Update Your Workflow

Change your action reference:
```yaml
# Before (Poetry)
uses: CVector-Energy/python-test@main

# After (UV)
uses: CVector-Energy/python-test@uv
```

### 3. Update Local Development

Replace `poetry` commands with `uv`:
```bash
# Install dependencies
poetry install  →  uv sync

# Run commands
poetry run <cmd>  →  uv run <cmd>

# Add dependencies
poetry add <pkg>  →  uv add <pkg>
```

## Requirements

Your project must have:
- `pyproject.toml` with `[project]` section
- `uv.lock` file (generated by `uv lock`)
- `requires-python` specified in `pyproject.toml`
